# Edge AI-Based Smart EV Charging Station

An advanced IoT simulation of a smart EV charging station. This project utilizes an ESP32 microcontroller, MQTT protocol, and the ThingsBoard cloud platform to monitor and manage power distribution across multiple charging bays.

## ✨ Key Features
* **Real-Time IoT Monitoring:** Live tracking of Voltage, Current, Power, and Temperature.
* **Edge AI Integration:** Predicts EV arrival probabilities and charging durations.
* **RPC Manual Override:** Two-way communication via ThingsBoard to manually toggle relays and throttle load.
* **Automated Safety Alarms:** Live overload current protection alerts.

## 🛠️ Tech Stack
* **Hardware:** ESP32, DHT22, Relays, LEDs (Wokwi Simulated)
* **Language/Protocol:** C++ (Arduino), MQTT, JSON
* **Cloud:** ThingsBoard Live
